# OpenStream

تطبيق أندرويد بلغة Kotlin (Jetpack Compose + Media3) مستوحى من وظائف وواجهة مشغّلات الوسائط مفتوحة المصدر.
Clean-room: لا كود ولا أصول ولا نصوص منقولة.

## التشغيل
1. افتح المجلد في Android Studio (إصدار حديث) وانتظر مزامنة Gradle
2. إن طلب Studio تحديث إصدارات الإضافات أو المكتبات فوافق
3. شغّل على محاكي أو جهاز (API 24 فأعلى)

## الميزات
بحث وتصفّح، تشغيل (Media3)، تنزيل (DownloadManager)، إشارات مرجعية، استئناف الموضع، عربي + إنجليزي مع RTL، بلا إعلانات ولا تتبّع.

## المصدر
`ArchiveProvider` يقرأ من Internet Archive (تتفاوت التراخيص حسب العنصر).
لإضافة مصدر آخر مرخّص لك: نفّذ `MediaProvider` وسجّله في `AppViewModel.providers`.

## ملاحظات
- لم يُبنَ المشروع هنا (لا Android SDK ولا شبكة)، فقد تظهر أخطاء صغيرة عند أول مزامنة
- المؤجَّل: Android TV، Chromecast (media3-cast)، شاشة الإعدادات
- راجع شروط أي مصدر قبل النشر. هذه ليست استشارة قانونية

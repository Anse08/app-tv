# استكشاف: تطبيق وسائط مفتوح المصدر على أندرويد (مرجع: CloudStream)

المصدر: صفحات المشروع العامة فقط. لا كود ولا أصول ولا نصوص منقولة (clean-room).

## الشاشات
1. الرئيسية: شريط بحث + شبكة بطاقات (ملصق + عنوان)
2. نتائج البحث (نفس الشبكة)
3. التفاصيل: ملصق، وصف، أزرار تشغيل / تنزيل / إشارة مرجعية، قائمة المصادر
4. المشغّل: ملء الشاشة، استئناف من آخر موضع
5. الإشارات المرجعية
6. الإعدادات (اللغة، المظهر)

## التدفقات
- بحث ثم تفاصيل ثم تشغيل
- حفظ إشارة مرجعية ثم الرجوع إليها لاحقًا
- تنزيل عنصر للمشاهدة دون اتصال
- استئناف المشاهدة من حيث توقفت

## الوظائف (خريطة الميزات)
| الميزة | الأولوية | الحالة في OpenStream |
|---|---|---|
| بحث وتصفّح | must | منجزة |
| تشغيل بث | must | منجزة (Media3) |
| إشارات مرجعية | must | منجزة |
| استئناف الموضع | should | منجزة |
| تنزيل | should | منجزة (DownloadManager) |
| دعم الهاتف والتلفاز | should | جزئي (واجهة الهاتف فقط) |
| Chromecast | could | مؤجلة (media3-cast) |
| نظام إضافات/مزوّدين | should | منجزة كواجهة `MediaProvider` داخلية |
| تعدد اللغات + RTL | should | منجزة (EN, AR) |
| بلا إعلانات ولا تتبّع | must | منجزة |

## خارج النطاق عمدًا
- مستودعات الإضافات الخارجية والمصادر التي تبثّ مواد محمية
- كود التطبيق المرجعي (GPL-3.0) واسمه وشعاره ونصوصه
- أي مصدر خلف تسجيل دخول أو جدار دفع

## المصدر الافتراضي للمحتوى
Internet Archive (أفلام ومواد المجال العام والمرخّصة بتراخيص مفتوحة) عبر واجهته العامة.
لا مفتاح API ولا حساب.
